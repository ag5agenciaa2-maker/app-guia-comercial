## CHECKLIST DE PREENCHIMENTO

Antes de enviar ao prompt de geração, confirme:

- [ ] Todos os serviços têm keyword alvo definida?
- [ ] Cada keyword inclui cidade?
- [ ] Cada serviço tem mínimo 5 perguntas de FAQ?
- [ ] Cores estão em HEX ou marcadas como "USAR DO DESIGN SYSTEM"?
- [ ] WhatsApp está no formato correto com DDD?
- [ ] Objetivo principal está definido?

> **Dica para o gerente:** Se o cliente não souber a keyword alvo, use a fórmula:
> `[profissão] + [serviço específico] + [cidade]`
